# Full backup every 4 hours

Only one schedule is active:
- Full backup every 4 hours.
- A rolling 4-hour interval is used from each successful backup.
- No hourly backup.
- No 7 PM special backup.
- No Tuesday/Friday 5 PM backup.
- A window's calls are sent only in that window; later windows do not repeat them.
- Deleted records remain retained so deletion can be marked DELETED.
