# VaultCall Premium UI System

## Visual direction
- Premium private-security / encrypted-vault aesthetic.
- Deep midnight background with restrained glass-like surfaces.
- Teal is the primary action accent; indigo is secondary.
- No generic Material-card overload; use large editorial hierarchy and generous spacing.
- Rounded corners 20–28dp, thin borders, subtle elevation.
- Typography: large numeric metrics, compact uppercase labels, clear secondary metadata.

## Dashboard hierarchy
1. Header: VaultCall mark + protection status.
2. Hero card: next data send time and backup mode.
3. Four metric tiles:
   - Saved calls
   - Current window
   - Last sent
   - Deleted detected
4. Backup timeline showing:
   - 4-hour incremental
   - 7:00 PM daily full
   - Tuesday/Friday 5:00 PM full
5. Recent activity feed.
6. Bottom navigation with Home / History / Schedule / Settings.

## Micro-interactions
- Animated progress ring for next scheduled send.
- Status chips: READY, SENDING, SENT, DELETED.
- Count-up animation for call totals.
- Subtle press scale on primary actions.
- Empty states use a simple vault illustration, never plain blank text.

## Logo
Use a unique shield + phone-wave mark, not a generic phone icon.
Brand wordmark: VAULTCALL.
